    How the value is fitted

    Model. log10(market cap) = 3.06 + 0.52 · log10(TVL) − 0.03 · age in years − 0.75 · 7-day growth, fitted by ridge regression (λ = 1, intercept unpenalised) on the 128 protocols whose token trades and whose market cap DefiLlama records as a positive number. A protocol that records no token gets 10prediction as its implied launch value. TVL does the work; age and growth enter with small fitted weights — fast TVL spikes revert, so the curve discounts them. In-sample R² = 0.21; the curve explains about a fifth of the variance, and the board says so instead of hiding it.

    Coverage. All 758 protocols in the snapshot are on the board — the 40-protocol watchlist, the 196 genuine pre-token protocols (58 of them at or above the $50M floor, including every watchlist name), and the 418 whose token already trades, kept as a separate live-comps view so a launch candidate is never confused with a token you can already buy. Two of those 418 are verified corrections to the snapshot's own record: USDD is a stablecoin that already trades (market cap about $1.44B) and TAO, behind Bittensor dTAO, already trades (about $2.19B) — the record lists no token for either, so both are treated as live, not as launches. A further 144 protocols record no token but are not launches at all: wrapped, staked and bridged products of tokens that already trade, centralised exchanges, and versioned copies. They stay on the board under “Not a launch”, each with the reason, so the radar says plainly where there is nothing to farm. No protocol is dropped, no name is hardcoded: the value follows from the snapshot's own figures.

    Farm plans. Each of the 196 genuine pre-token protocols carries a plan built from its own record — its chains set the gas bill, its category sets the actions, its TVL band sets the position size ($100–$500). Every step names a dollar cost and a time; the plan total is shown on the row. Live protocols carry a positioning plan instead, labelled as such, and excluded products carry a verdict, not a farm.

    Reproduce it. Run main.ts on the sealed snapshot; it refits the curve, reruns all four validations, rebuilds this board, and prints the same numbers. Nothing on this page is typed in by hand from a leaderboard.
